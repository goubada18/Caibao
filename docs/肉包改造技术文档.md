1. 项目概述
1.1 肉包项目简介
肉包（Roubao）是由 Turbo1123 开发的一款完全开源（MIT协议）的Android原生AI自动化工具，已收获2000+ Star。它基于视觉语言模型（VLM），使用Kotlin纯原生开发，无需电脑、无需Root、无需数据线，安装App即可运行。

核心定位：首款无需PC的开源AI手机自动化助手。

技术关键词：VLM + Native Kotlin + Shizuku + Tools/Skills 双层Agent架构。

1.2 为什么选择肉包作为改造基座
维度	肉包优势
原生Android	用Kotlin重写了整个MobileAgent框架，原生运行在Android设备上
Shizuku集成	通过Shizuku获得ADB级权限，无需Root
双层架构	实现了Tools + Skills双层Agent框架，受Claude Code启发
高度可定制	支持通义千问、GPT-4V、Claude及本地Ollama等多种模型后端
MIT协议	完全开源，可自由修改和商用
1.3 改造愿景
在保留肉包优秀的Tools/Skills决策框架和UI的基础上，重构“感知层”（眼睛）和“执行层”（手脚），实现：

速度提升5-10倍：用本地UI树解析替代截图→VLM分析

反检测能力增强：用INJECT_EVENTS物理事件注入替代input tap shell命令

安全性保障：内置黑名单拦截，防止AI执行金融类敏感操作

多Agent协作：任务规划与执行解耦

3.2.3 Tools层 (tools/) —— 原子能力集合
Tools层负责执行最底层、可复用的物理或系统操作：

input：文本输入

shell：执行系统命令

deep_link：DeepLink跳转

search_apps：智能搜索已安装应用

改造要点：保留Tools层的接口定义，但替换tap/swipe的底层实现。

3.2.4 Skills层 (skills/) —— 用户意图封装
Skills层负责将自然语言意图映射为可执行策略：

Delegation（委托模式） ：通过DeepLink直接调用具备AI能力的应用

GUI自动化模式：面向普通应用的标准Agent循环

改造要点：Skills层基本不变，只优化GUI自动化模式中的感知步骤。

3.2.5 VLM层 (vlm/)
封装对云端大模型API的调用（豆包/GPT-4o/Claude等）

Prompt管理：System Prompt和User Prompt的组装

6.3.3 MotionEvent构造要点
kotlin
// PointerProperties：定义触摸点属性
val properties = arrayOf(PointerProperties().apply {

6.4.2 贝塞尔曲线实现
滑动轨迹使用二次贝塞尔曲线，控制点在起点和终点之间加入随机偏移，形成自然弧线：

text
P(t) = (1-t)²·P₁ + 2(1-t)·t·Pc + t²·P₂
P₁：起点

P₂：终点

Pc：控制点（随机偏移）

t：0→1 的插值参数

private fun executeWithUITree(elements: List<UIElement>, instruction: String) {
    // 匹配目标控件
    val target = findBestMatch(elements, instruction)
    // 安全拦截
    if (blacklistGuard.isBlocked(target)) {
        showBlockedWarning()
        return
    }
    // 人性化执行
    val (x, y) = Humanizer.applyOffset(target.centerX, target.centerY)
    touchInjection.injectTap(x, y)
    Thread.sleep(Humanizer.randomDelay())
}
